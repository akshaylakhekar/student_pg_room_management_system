# student_pg_room_management_system
PG Management System is a web application developed using Java 17, Spring MVC, Spring JDBC, MySQL, JSP, and JSTL.  The main objective of this project is to simplify paying guest accommodation management. It helps manage properties, rooms, tenants, room allocation, rent payments, and receipts.  I implemented a three-tier MVC architecture with separate controllers, services, and DAOs. I also worked on role-based access for Admin and Student portals, search functionality, and a dashboard to track room occupancy and revenue.  This project helped me improve my Java, Spring MVC, database management, and backend development skills.
